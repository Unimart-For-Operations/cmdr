# Neovim Setup

This module manages two Neovim configurations:

| Config | Description | Source | Command |
|--------|-------------|--------|---------|
| nvim-astro | AstroNvim with personal customizations (PRIMARY) | In-repo config deployed by Home Manager | `nvim`, `nvim-astro` |
| nixvim | Nixvim declarative config, Catppuccin Frappe | Generated by Nix | `nixvim` |

## How NVIM_APPNAME Works

The `NVIM_APPNAME` environment variable tells Neovim where to look for configuration:

- `NVIM_APPNAME=nvim-astro nvim` → reads config from `~/.config/nvim-astro/`

Plugin data and state are isolated:
- Config: `~/.config/nvim-{distro}/`
- Data: `~/.local/share/nvim-{distro}/`
- State: `~/.local/state/nvim-{distro}/`
- Cache: `~/.cache/nvim-{distro}/`

## Usage

```bash
nvim              # Launch AstroNvim (default)
nvim-astro        # Launch AstroNvim explicitly
nixvim            # Launch Nixvim (declarative)
```

## AstroNvim (`nvim-astro`)

A personal fork of the AstroNvim template, stored directly in this repository and deployed by Home Manager to `~/.config/nvim-astro/`.

**Config location in repo:** `home/04-modules/tui/graduated/nvim/nvim-astro/`

Home Manager deploys the entire directory to `~/.config/nvim-astro/` as read-only Nix store symlinks. Two wrapper scripts in `~/.local/bin/` handle launching:
- `nvim-astro` — sets `NVIM_APPNAME=nvim-astro` + `LAZY` env vars, execs the real neovim binary via absolute Nix store path
- `nvim` — delegates to `nvim-astro` (single line to change for distro swap)

Mason is fully disabled — all LSP servers, formatters, and linters are provided by Nix (`lsp-tools.nix`). Formatting is handled by conform.nvim, not LSP.

### Updating AstroNvim config

Edit files in `home/04-modules/tui/graduated/nvim/nvim-astro/`, commit, then apply:

```bash
make apply HOST=apple-studio-m2-max
```

### Updating plugins (Lazy.nvim)

AstroNvim uses Lazy.nvim. The lock file is stored in `~/.local/share/nvim-astro/lazy-lock.json` (the writable XDG data dir), not in `~/.config/nvim-astro/` which is read-only Nix store symlinks.

```bash
nvim-astro
# Inside nvim:
:Lazy update

# Sync the updated lock file back to the repo:
cp ~/.local/share/nvim-astro/lazy-lock.json \
   home/04-modules/tui/graduated/nvim/nvim-astro/lazy-lock.json
git add home/04-modules/tui/graduated/nvim/nvim-astro/lazy-lock.json
git commit -m "chore: update nvim-astro lazy-lock.json"
make apply HOST=apple-studio-m2-max   # re-seeds the lock file from the repo
```

## Nixvim (`nixvim`)

Fully declarative Neovim configuration built by Nix. Configured in `nixvim-config.nix`.

**Features:**
- Catppuccin Frappe theme
- Telescope fuzzy finder
- Full LSP support (10 language servers)
- Treesitter syntax highlighting
- Neo-tree file explorer
- Gitsigns git integration
- Lualine + Bufferline
- Which-key keybinding hints
- nvim-cmp + LuaSnip completion
- Comment.nvim, nvim-autopairs, nvim-surround
- Render-markdown inline preview
- ToggleTerm terminal
- Indent-blankline

**Key bindings:**
- Leader: `<Space>`, local leader: `,`
- Telescope: `<leader>ff/fg/fb/fh/fw/fo/fc`
- LSP: `gd/gD/gr/gi/K/<leader>lr/la/lf`
- Buffer: `]b/[b/<leader>bd`
- Window: `<C-h/j/k/l>`
- File explorer: `<leader>e`
- Terminal: `<C-\>`
- Save: `<C-s>`

To modify: edit `home/04-modules/tui/graduated/nvim/nixvim-config.nix` and rebuild.

## LSP Tools

LSP servers, formatters, and linters are installed **globally via Nix** (`lsp-tools.nix`), not per-distribution with Mason.

**Language Servers:** lua-language-server, nil (Nix), typescript-language-server, bash-language-server, pyright, terraform-ls (from cli/terraform), yaml-language-server, vscode-langservers-extracted (HTML/CSS/JSON/ESLint), gopls (Go), dockerfile-language-server (Dockerfile), marksman (Markdown)

**Formatters:** stylua, nixpkgs-fmt, prettier, black, shfmt

**Linters:** shellcheck

**Tools:** tree-sitter, ripgrep, fd (Telescope dependencies)

## Module Files

- `default.nix` — installs neovim + nixvimWrapped, deploys `nvim-astro/` via xdg.configFile, provides `nvim`/`nvim-astro` wrapper scripts, activation scripts for lazy-lock.json and lazy.nvim pre-fetch
- `lsp-tools.nix` — global LSP servers, formatters, linters (Mason is disabled)
- `nixvim-config.nix` — declarative nixvim configuration
- `nvim-astro/` — AstroNvim config (deployed by Home Manager to `~/.config/nvim-astro/`)

## Troubleshooting

### AstroNvim plugins not loading

```bash
nvim-astro   # Launch
:Lazy        # Check status
# If broken:
rm -rf ~/.local/share/nvim-astro
nvim-astro   # Plugins reinstall on next launch
```

### LSP not working

```bash
which lua-language-server
which typescript-language-server
# If missing:
make apply HOST=<host>
```
